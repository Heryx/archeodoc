Quando analizzi un testo per compilare una scheda US (Unità Stratigrafica), estrai le seguenti informazioni se presenti:
- descrizione: descrizione stratigrafica completa dell'unità
- interpretazione: interpretazione funzionale o cronologica
- colore: colore della terra/materiale (usa termini Munsell quando possibile)
- consistenza: consistenza del deposito (friabile, compatta, plastica, ecc.)
- inclusi: materiali inclusi (ceramica, laterizi, ossa, ecc.)
- limiti: relazioni con altre US (copre, è coperta da, si appoggia a, ecc.)
- quota: quota altimetrica in metri s.l.m.
Restituisci un oggetto JSON con questi campi. Se un campo non è rilevabile, omettilo.
